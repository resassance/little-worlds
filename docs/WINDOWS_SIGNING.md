# Подпись Windows

Игра `little-worlds.exe` и программа запуска Web `start-windows.exe` подписаны Authenticode сертификатом `resassance / Little Worlds`, RSA 3072 и SHA-256.

Сертификат самоподписанный. Он позволяет проверить подпись и целостность файла, но не подтверждает издателя через доверенный удостоверяющий центр. Windows и SmartScreen могут показывать предупреждения о неизвестном издателе. Установка сертификата в системное хранилище не является частью выпуска.

Публичный сертификат: `platform/windows/release-certificate.pem`.

SHA-256 сертификата: `2fc2053cb6a3d1b029e76dd0f426ec0da30dc2d6e4070745c837de89320e277a`.

Публичный сертификат также включён в Windows ZIP и Web ZIP. Закрытый ключ PFX и пароль находятся вне репозитория и публичных файлов. Приватный архив для владельца содержит ключи обеих платформ.

Повторная подпись выполняется скриптом `tools/sign_windows.py` с osslsigncode. Скрипт проверяет подпись с явно указанным публичным сертификатом; такая проверка не означает, что сертификат входит в доверенные корни Windows. Метка времени TSA в текущую подпись не включена. Содержимое исполняемых файлов и встроенный пакет игры при подписи сохраняются.

Для публично доверенной подписи потребуется сертификат издателя от удостоверяющего центра или доступ владельца к сервису доверенной подписи.

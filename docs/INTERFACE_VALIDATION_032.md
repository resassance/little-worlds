# Проверка интерфейса 0.3.2-test.1

## Пройдено

- Выбор отдельного здания первым нажатием, переход к его поселению, показатели реальных материалов и работы, схема ткацкой.
- Карточки и фильтры архива, раскрытие событий, сохранение раскрытия после новой записи, переиспользование узлов при обновлении.
- Касания по материалу стройки и по всплывающему фильтру архива через InputEventScreenTouch.
- Окна 1440×900, 2160×1080 при плотности 2,25, 2400×1080 и 1080×2400 при плотности 3, планшет 1180×820 при плотности 2. Компактный масштаб сохраняет области касания от 48 dp.
- Существующие проверки сведений о поселениях и людях, мобильных диалогов, жестов и всплывающих меню.
- Экспортированные Linux и Web запускаются. В Web загружаются миры прежних форматов, сохраняются v15, стада, традиции, текущая работа и грузы.
- В браузере с сенсорным вводом проверены 640×360 при плотности 3, 360×800 при плотности 3 и 960×480 при плотности 2,25. Касание открывает инструменты; ошибок консоли нет.
- Android versionCode 25, версия 0.3.2-test.1. Подпись и имя пакета совпадают с 0.3.1.
- В исходниках, тестах и сборочных скриптах комментарии и docstring отсутствуют.

Проверки выполнялись в Linux с программным рендерингом llvmpipe и Chromium SwiftShader. Указанные размеры и плотности воспроизводились программно; это не замер кадров на физическом телефоне. Скриншоты используют подготовленный мир для просмотра разных построек.

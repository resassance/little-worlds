# Критерии завершения первой версии

Объём по PLAN.md и первому циклу HUMANITY.md: возраст и поколения; независимое развитие до ранних городов/средневекового уклада; климат и экология; мореплавание, экспедиции, первый контакт и постепенный обмен; оформление, обучение, настройки и платформенные сборки. Промышленность, современность, войны, несколько рас и мультиплеер обозначены в исходном плане как расширения.

- [x] Местные производственные цепочки, материалы и последующие технологии влияют на хозяйство.
- [x] Обмен, контакты и переселение передают людей/знания без бесплатных ресурсов.
- [x] Климат задаётся настройкой мира, ручной биом — кистью; параметры остаются стабильными при расширении.
- [x] Сезоны, влажность, холод и восстановление леса учитываются в симуляции.
- [x] Большой мир хранит пустой океан разреженно; неактивные участки выгружаются; дальняя жизнь не зависит от камеры.
- [x] Рыболовство, лодки, порты, парусные суда, дальние маршруты и первый контакт работают.
- [x] Экспедиции имеют экипаж, путь, снабжение, риск, возврат и сохранённый прогресс.
- [x] Звук, краткое обучение, настройки и обработка паузы приложения работают.
- [x] Яндекс SDK: готовность, пауза/возобновление, доступная реклама и облачная запись через отдельный платформенный слой.
- [x] Windows, Linux, Android и Web собраны и проверены доступными средствами.
- [x] Сквозной сценарий двух климатически разных материков проходит через контакт, сохранение и загрузку.
- [x] Проверены ресурсный баланс, поколения, миграция старых сохранений, ошибки и интерфейс на коротком экране.

# Выпуск 0.2.0 · 2026-10-11

## Объём

Первый законченный игровой цикл песочницы: создавать и заселять земли, наблюдать поколения и независимое развитие, вмешиваться стихиями, ждать морских контактов, сохранять и продолжать мир. Целевые платформы: Windows x86_64, Linux x86_64, Android arm64/x86_64 и Web для Яндекс Игр. Движок Godot 4.7.2, Compatibility.

Морская скорость — масштаб времени симуляции, а не физически достоверная историческая скорость. У лодки небольшая дальность из-за припасов; парусник делает достижимыми очень далёкие острова. Шторм задерживает судно и повреждает его; смерть последнего моряка разрешается на следующем шаге и сохраняется корректно.

11 технологий: хранение пищи, плотничество, севооборот, записи, обработка камня, керамика, ткачество, металлургия, городское управление, прибрежное мореплавание, паруса и навигация. Они требуют местной практики и инфраструктуры. Переход этапа требует трёх устойчивых дней и фактического применения. Потеря мастера останавливает применение, сохраняя рецепт и историю.

Большое поселение может расширять склад, когда запас упирается во вместимость. Требуются обычная древесина, доставка и работа; ёмкость растёт до возможности держать запас на 12 дней для развития и экспедиций. Еда при строительстве не добавляется.

## Хранение и производительность

У неактивных регионов есть сжатый кэш на диске с проверкой целостности. Целевой бюджет горячего кэша — 128 регионов; места жителей, поселений и огня закреплены и могут увеличить этот бюджет. Чтение карты не меняет её состояние. Сохранение и загрузка обрабатывают по одному региону; манифест с SHA-256 записывается последним. Ошибка кэша блокирует замену последнего корректного сохранения.

Камера не выбирает, кто «живёт»: при текущем лимите все жители считаются точно. Большая суша создаётся с бюджетом по кадрам. Основной цикл сохраняет очередь шагов при перегрузке; он не выбрасывает прожитое виртуальное время. Версия 0.2.0 использует общие планы поселений, индексы жителей и пакеты до 32 заданий. Агрегированная модель для 10 000+ жителей относится к следующему этапу; [подробности и ограничения](POPULATION.md).

## Платформы

Linux и Windows содержат встроенный PCK. Android APK 0.2.0: package `org.littleworlds.sandbox`, minimum SDK 24, target SDK 36, архитектуры arm64-v8a и x86_64; подпись debug v2/v3. Для магазинного выпуска нужен ключ владельца приложения. Web не использует потоки; ZIP имеет `index.html` в корне, запускается по HTTP.

`GamePlatform` и `platform/yandex_bridge.js` отделяют SDK от мира. Готовность сообщается после создания игры; паузы площадки/вкладки блокируют симуляцию и звук. Видео запускается только явным пунктом меню; повторный callback не дублирует награду. Облако хранит сжатый снимок v8 без запроса расширенных scopes; предел упакованной записи — 180 000 символов, исходного JSON — 8 МиБ. При недоступном SDK остаются локальная игра и сохранение.

Доступные проверки и их фактические границы записаны в [VALIDATION.md](VALIDATION.md). Для запуска на Windows-ПК, физическом телефоне и публикации в кабинете Яндекс Игр нужны соответствующие устройства/аккаунт. Индустриальная/современная эпохи, войны, мультиплеер и подробная политика остаются отдельным следующим циклом.

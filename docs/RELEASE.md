Морская скорость — масштаб времени симуляции, а не физически достоверная историческая скорость. У лодки небольшая дальность из-за припасов; парусник делает достижимыми очень далёкие острова. ## Хранение и производительность

У неактивных регионов есть сжатый кэш на диске с проверкой целостности. Целевой бюджет горячего кэша — 128 регионов; места жителей, поселений и огня закреплены и могут увеличить этот бюджет. Чтение карты не меняет её состояние. Сохранение и загрузка обрабатывают по одному региону; манифест с SHA-256 записывается последним. Ошибка кэша блокирует замену последнего корректного сохранения.

Камера не выбирает, кто «живёт»: при текущем лимите все жители считаются точно. Большая суша создаётся с бюджетом по кадрам. Основной цикл сохраняет очередь шагов при перегрузке; он не выбрасывает прожитое виртуальное время. Версия 0.2.0 использует общие планы поселений, индексы жителей и пакеты до 32 заданий. Агрегированная модель для 10 000+ жителей относится к следующему этапу; [подробности и ограничения](POPULATION.md).

## Платформы

Linux и Windows содержат встроенный PCK. Android APK 0.2.0: package `org.littleworlds.sandbox`, minimum SDK 24, target SDK 36, архитектуры arm64-v8a и x86_64; подпись debug v2/v3. Для магазинного выпуска нужен ключ владельца приложения. Web не использует потоки; ZIP имеет `index.html` в корне, запускается по HTTP.

`GamePlatform` и `platform/yandex_bridge.js` отделяют SDK от мира. Готовность сообщается после создания игры; паузы площадки/вкладки блокируют симуляцию и звук. Видео запускается только явным пунктом меню; повторный callback не дублирует награду. Облако хранит сжатый снимок v8 без запроса расширенных scopes; предел упакованной записи — 180 000 символов, исходного JSON — 8 МиБ. При недоступном SDK остаются локальная игра и сохранение.

Индустриальная/современная эпохи, войны, мультиплеер и подробная политика остаются отдельным следующим циклом.

## Оформление релизов

Описание содержит изменения, заметные игроку, и инструкции запуска. Результаты тестов, число проверок, служебные манифесты и рабочие заметки не публикуются в описании и вложениях релиза. К сборкам прилагается `SHA256SUMS.txt` для проверки целостности файлов.

В Web-архив входят `start-windows.exe`, `start-linux` и `README.txt`. Они нужны для локального запуска; на сайт или в Яндекс Игры загружаются только `index.html` и файлы `index.*`.

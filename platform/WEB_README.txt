МАЛЕНЬКИЕ МИРЫ — БРАУЗЕРНАЯ ВЕРСИЯ

Распакуйте весь архив в отдельную папку.

Windows: откройте start-windows.exe.
Linux x86_64: запустите start-linux. Если нужно, разрешите запуск:
  chmod +x start-linux
  ./start-linux

Игра откроется в браузере. Если вкладка не открылась автоматически,
перейдите на http://127.0.0.1:18765/.
Оставьте окно запуска открытым, пока играете.
Устанавливать Python или Godot не нужно.

index.html нельзя запускать двойным щелчком: браузер ограничивает
загрузку файлов игры с диска. Программа запуска решает это,
предоставляя игру через локальный HTTP-сервер.

Сохранения находятся в данных браузера для адреса
http://127.0.0.1:18765/. Используйте тот же браузер и обычный режим.
Очистка данных сайта удалит эти сохранения.

ДЛЯ ПУБЛИКАЦИИ

На сайте разместите index.html и все файлы index.* вместе.
Программы запуска и README.txt нужны только для локальной игры.
Для Яндекс Игр упакуйте только index.html и index.* в ZIP,
чтобы index.html находился в корне архива.

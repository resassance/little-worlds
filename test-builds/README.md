# performance-04 · 0.2.6-test.4

Непрерывная кисть показывает применённую землю до завершения подробной подготовки карты. Совместимые прямые сегменты объединяются. Правки вдали от населения сохраняют независимую навигацию; вырубка не сбрасывает наземные пути. Сокращены повторные хозяйственные расчёты и обновления летописи, старый кеш удаляется порциями.

[Android Preview](little-worlds-android-preview.apk?raw=true) · [Windows](little-worlds-windows-test.zip?raw=true) · [Linux](little-worlds-linux-test.zip?raw=true) · [Web](little-worlds-web-test.zip?raw=true) · [Исходники](little-worlds-godot-test.zip?raw=true)

APK обновляет предыдущие Preview, сохраняя их миры. Основная игра использует отдельное приложение и сохранения.

Если ссылка не скачивается, откройте файл выше и нажмите Download raw file. Для Web распакуйте весь архив и запустите start-windows.exe или start-linux.

Во время непрерывного рисования развитие временно ждёт правки. После отпускания или остановки движения работа продолжается. Большие миры ещё ограничивают фактическую скорость ×5.

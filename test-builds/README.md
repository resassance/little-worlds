# simulation-05 · 0.2.6-test.5

Морское планирование проверяет экипаж и запасы перед поиском пути, изучает берега постепенно и распределяет неудачные попытки между циклами. Автосохранение готовит независимый снимок; дальнейшая запись идёт одновременно с развитием мира.

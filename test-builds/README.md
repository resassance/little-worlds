# atlas-03 · 0.2.6-test.3

Новый интерфейс в стиле бумажного атласа. Оттенки кожи и одежды, предпочтения ремесла и личные цели жителей. Варианты крыш и названия поселений по местности. Исправлено сохранение расписания погоды.

[Android Preview](little-worlds-android-preview.apk?raw=true) · [Windows](little-worlds-windows-test.zip?raw=true) · [Linux](little-worlds-linux-test.zip?raw=true) · [Web](little-worlds-web-test.zip?raw=true) · [Исходники](little-worlds-godot-test.zip?raw=true)

APK обновляет Preview из weather-02, сохраняя его миры. Основная игра остаётся отдельным приложением с собственными сохранениями: её прежний ключ подписи недоступен в восстановленном рабочем окружении.

Если ссылка не скачивается, откройте файл выше и нажмите Download raw file. Для Web распакуйте весь архив и запустите start-windows.exe или start-linux.
